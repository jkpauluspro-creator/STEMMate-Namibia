Synchronisation and recovery

What does synchronisation mean?

Synchronisation sends your completed session plans from this device to the receiving server. Saving a plan and sending it are two separate steps.

  • Pending: your plan is stored on this device but the server has not confirmed receipt.
  • Sync all pending: send locally saved plans to the receiving server when it is available.
  • Synced: the receiving server has confirmed receipt of your plan.
  • If sending fails: your plan remains stored on this device. Select Retry sync when the receiving server is available again.

Local data & shared-device privacy

Anyone using this same browser profile can potentially access locally saved STEMMate plans. There are no user accounts or secure sign-out in this demonstration.

1. Export local data

Download a JSON backup of saved activities, the unfinished draft and completed plans before clearing anything. The download can contain session-plan text and must be stored securely.

2. Clear this browser's locally saved data

This permanently deletes STEMMate's saved activities, current draft and completed plans from this browser profile. It does not erase plans already received by the Node.js server, and it does not remove the cached application files.
